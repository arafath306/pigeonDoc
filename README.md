# Pigeon Social Documentation

This is the official documentation website for **Pigeon Social**. It provides comprehensive guides, feature details, FAQs, and use cases for regular users, creators, and businesses using the Pigeon platform.

## Key Features

- **Rich Documentation:** Detailed guides covering everything from getting started and joining communities to sending end-to-end encrypted messages.
- **Feature Showcase:** A complete and detailed list of all Pigeon Social features, including Voice Posts, Music Attachments, and Screenshot Protection.
- **Direct App Download:** Integrated buttons to download the latest Android release APK (`app-release.apk`) directly from the website.
- **Responsive & Modern UI:** A beautiful, fast, and responsive interface with full dark mode support, built using modern web technologies.

## Getting Started Locally

To run this documentation site on your local machine:

1. **Install dependencies:**
   Make sure you have Node.js installed, then run:
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **View the site:**
   Open your browser and navigate to `http://localhost:5173/`.
